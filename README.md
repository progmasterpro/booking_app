### Backend-сервис для бронирования отелей на FastAPI: регистрация и авторизация, отели и номера, бронирования, кеширование и фоновые задачи.

### Возможности

- регистрация и авторизация пользователей, JWT-аутентификация;
- создание и получение отелей, поиск, фильтрация и пагинация;
- создание и получение номеров;
- бронирование номеров с расчётом стоимости проживания;
- Удобства отелей и номеров: парковка, бассейн, тренажёрный зал, Wi-Fi и другие дополнительные услуги;
- загрузка и обработка изображений;
- кеширование ответов в Redis;
- фоновые и периодические задачи на Celery / Celery Beat.

### Стек

| Область | Технологии |
|---|---|
| Язык и фреймворк | Python 3.13, FastAPI, Pydantic |
| База данных | PostgreSQL, SQLAlchemy 2 (async), asyncpg, Alembic |
| Кеш и очереди | Redis, Celery, Celery Beat |
| Безопасность | JWT |
| Тесты | pytest, pytest-asyncio, HTTPX |
| Инфраструктура | Docker, Docker Compose, Nginx |

## API

Полное интерактивное описание — в Swagger: http://localhost:7777/docs

Основные группы эндпоинтов:

| Группа | Назначение |
|---|---|
| `/auth` | регистрация, вход, выход, текущий пользователь |
| `/hotels` | отели, поиск, фильтрация, пагинация |
| `/rooms` | номера отелей |
| `/bookings` | бронирования |
| `/facilities` | удобства |
| `/images` | загрузка изображений |


### Архитектура

Проект разделён на слои:

- `api` — эндпоинты и роутеры;
- `schemas` — схемы Pydantic для валидации данных;
- `models` — модели SQLAlchemy;
- `services` — бизнес-логика;
- `tasks` — фоновые задачи Celery.
